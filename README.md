# ⭐ Logic Box – Pattern Generator & Number Analyzer

> 🐍 A simple and interactive Python console application for generating star patterns and analyzing numbers in a selected range.

---

## 🚀 Features

### 🔺 1. Pattern Generator
- Enter the number of rows.
- Generates an increasing `*` pattern.
- Example:

```text
*
**
***
****
*****
```

### 🔢 2. Number Analyzer
- Enter a starting and ending number.
- Checks every number as **Even** or **Odd**.
- Calculates the **sum of all numbers** in the selected range.

### 🚪 3. Exit
- Safely exits the program with a goodbye message.

---

```bash

```

4. Select an option from the menu.
5. Follow the instructions displayed in the terminal.

---

## 🧠 How It Works

The program continuously displays a menu using a `while` loop.  
When the user chooses:

- **Option 1** → it generates a star pattern based on the number of rows.
- **Option 2** → it analyzes each number in the given range, identifies whether it is even or odd, and calculates the total sum.
- **Option 3** → it exits the program.
- Any other choice → it displays an invalid-choice message.
